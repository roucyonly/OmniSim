      "agent_updates": [

  ```json

    "data": { "day": 3, "content": "今日令狐冲在后山独练剑法..." }

  ```

### 7.2 一键初始化 API
- `POST /api/world/init/huashan`:
  1. 创建世界（16×16）
  2. 生成华山地图（调用 themes/huashan/map.py）
  3. 生成华山人物（调用 themes/huashan/characters.py）
  4. 为所有 T1 角色生成第一天计划（调用 planner）
  5. 返回 world_id

### 7.3 模拟控制 API
- `POST /api/world/{id}/start` — 开始模拟（自动 tick 推进 + WebSocket 推送）
- `POST /api/world/{id}/pause` — 暂停
- `POST /api/world/{id}/speed` — 调整速度

### 7.4 前端联调
- 前端调用初始化 API 创建华山世界
- 连接 WebSocket 接收 tick 推送
- MapCanvas 实时更新角色位置和状态
- LogPanel 实时追加行为日志
- 验证点击聚焦功能

### 7.5 端到端验证场景

**场景：令狐冲在华山的一天**

| 时辰 | 令狐冲 | 岳灵珊 | 岳不群 | 宁中则 |
|------|--------|--------|--------|--------|
| 卯时 | 起床，到练剑场 | 起床，到练剑场 | 正气堂早课 | 指导弟子 |
| 辰时 | 练剑 | 与令狐冲切磋 | 处理门务 | 巡查 |
| 巳时 | 午饭（食堂） | 午饭（食堂） | 午饭 | 午饭 |
| 午时 | 自由活动 | 找令狐冲聊天 | 授徒 | 教女儿剑法 |
| 未时 | 练功 | 练功 | 修炼紫霞神功 | 修炼 |
| 申时 | 晚饭 | 晚饭 | 晚饭 | 晚饭 |
| 酉时 | 在宿舍休息 | 在宿舍休息 | 与宁中则议事 | 与岳不群议事 |
| 戌时 | 休息 | 休息 | 密谋（独自） | 休息 |
| 亥时 | 睡觉 | 睡觉 | 睡觉 | 睡觉 |

**验证要点**：
1. 角色按计划在地图上移动（练剑场→食堂→宿舍，位置变化可见）
2. 令狐冲与岳灵珊在练剑场相遇并切磋，日志有记录
3. 切磋后双方 **关系值变化**（intimacy +2），记忆中有 `involved_agents` 和 `emotion_tag`
4. 对话内容自然（接入 LLM 后）
5. 反思系统运行：令狐冲反思"今日与小师妹切磋，她的剑法有进步"
6. 反思更新对岳灵珊的 **impression**
7. 岳不群密谋时产生负面情绪变化（如果骰子失败）
8. **主动行为验证**：午时自由活动期间，令狐冲主动找岳灵珊聊天（因为 extraversion=0.9, intimacy 高）
9. 运行 3 天后，每天有纪事（或跳过）
10. 前端地图、日志、交互全部正常
